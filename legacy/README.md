# Legacy signatures

Retired signatures, kept as they last stood. Nothing in the build reads this
directory; these are keepsakes, not inputs, and they are never regenerated.

Each file is a complete standalone SVG. Open one in a browser and it still
animates, because the signature has never depended on anything external.

## `s89-detroit-falcons.svg`

Leyla's SMJHL signature, in its final state before her call-up to the Tampa Bay
Barracuda. Retired 2026-08-25.

|  |  |
|---|---|
| Club | Detroit Falcons (DET), SMJHL |
| Season shown | S89 |
| TPE | 819 total, 425 applied, 394 banked |
| Regular season | 66 GP, 11 G, 51 A, 62 P, +21 |
| Playoffs | 8 GP, 3 G, 5 A, 8 P |

Two things about it are gone from the live signature and will not come back on
their own:

- **The Falcons crest is inlined by hand.** It predates the pipeline that now
  pulls crests from the league sprite stacks, and it was pasted in through the
  GitHub web UI rather than fetched. The same artwork is still served at
  `index.simulationhockey.com/stack/smjhl.stack.svg#Detroit`, but this file holds
  the copy she actually posted with.
- **The accent is Detroit red** (`#d02128` dark, `#b0161d` light), from before the
  palette became club-driven.

The seasons before S89 were never captured. The automation only began part-way
through S89, so this is the single surviving snapshot of the Detroit era.
